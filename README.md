# Lei Tzu-Yi — Portfolio

Personal engineering portfolio published with GitHub Pages.

The site is intentionally static: plain HTML, CSS, and a small amount of JavaScript. There is no framework build step or runtime dependency.

## Focus

- Operating systems and systems software
- Containers and Linux kernel primitives
- Networking and storage
- Software quality and reliability
- AI foundations and applied computer vision

## Local preview

Any static HTTP server works. For example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

GitHub Pages publishes the repository root from `main`.
